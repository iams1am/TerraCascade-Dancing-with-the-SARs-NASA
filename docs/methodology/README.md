# Methodology

TerraCascade separates direct observations from calculations and context:

- **OBSERVED** — a value directly present in a verified NISAR product.
- **DERIVED** — a transparent calculation performed from observed values.
- **CONTEXTUAL** — supporting Earth or geographic information.
- **POTENTIAL** — a cautious implication that requires further verification.

The current repository has completed discovery and scientific preview for one
NASA/ASF sample GUNW product. The website presents the verified unwrapped
phase and coherence preview in a bounded projected region. It does not
convert phase to displacement, claim persistence from one pair, or infer a
deformation cause.

The current sample has historical surrogate-era acquisition dates. It is
useful for demonstrating the processing and provenance workflow, but must not
be presented as a current operational NISAR acquisition.
