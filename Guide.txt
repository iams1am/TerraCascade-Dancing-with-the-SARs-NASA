## NASA Space Apps Challenge 2026 — Dancing with the SARs

**Project:** TerraCascade  
**Tagline:** *See the change. Understand the chain.*

# 1. Project Objective

[certain] TerraCascade is intended to use NISAR radar observations to detect, visualize, and explain changes occurring on Earth's surface. Your proposal explicitly centers the project on NISAR-derived surface change rather than using NASA data merely as a decorative map layer. :chatgpt-content-reference{index="1"}

## October MVP objective

Build a working web application in which a user can:

1. Open TerraCascade.
2. Select one real demonstration location.
3. See a real NISAR-derived deformation layer.
4. Examine at least two temporal observations/products.
5. See numerical measurements derived from the data.
6. See a change-over-time visualization.
7. Understand whether the change appears persistent.
8. Open **Change DNA**.
9. Open **Cascade Mode**.
10. distinguish:
   - Observed evidence
   - Derived results
   - Contextual information
   - Potential implications
11. See the underlying datasets and sources.

# 4. Scientific Rule #1

## Never invent measurements

[certain] Values such as:

```text
-4 mm
-11 mm
-19 mm
-27 mm
```

in the proposal are illustrative examples, not verified observations. :chatgpt-content-reference{index="3"}

Therefore:

```text
DO NOT:
hardcode impressive-looking displacement numbers.

DO:
derive every displayed scientific number from the
actual processed data.
```

Every displayed measurement should ultimately answer:

```text
Where did this value come from?
Which NISAR product?
Which observation?
Which variable?
Which processing step?
Which units?
```

---

# 5. Scientific Rule #2

## TerraCascade detects change; it does not diagnose causes automatically

[certain] Your proposal correctly recognizes that SAR observations alone cannot prove that groundwater extraction caused subsidence, that a flood will happen, or that infrastructure has been damaged. :chatgpt-content-reference{index="4"}

Use wording such as:

```text
OBSERVED
Surface displacement signal detected.

DERIVED
The signal persists across the available observations.

CONTEXTUAL
The area contains roads and dense development.

POTENTIAL
Persistent deformation could increase infrastructure
exposure and should be investigated further.
```

Do **not** write:

```text
NASA detected an upcoming disaster.
```

or:

```text
This satellite proves groundwater caused the subsidence.
```
